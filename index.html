Para quem é este site

Para quem quer aprender e não tem como pagar um curso. Em especial, para jovens que querem ganhar uma renda extra: vendendo doces, fazendo um currículo, divulgando um serviço ou organizando os gastos da casa.

Você não precisa saber nada de computador. Cada aula explica as palavras difíceis e mostra o passo a passo. Muitas coisas dá para fazer só com o celular.

Como usar em 3 passos

  1. Escolha uma trilha. Cada trilha é uma ferramenta, como Excel ou Canva.
  2. Faça as aulas na ordem. Comece pelo nível Básico e depois siga para o Intermediário.
  3. Pratique. Toda aula tem um exercício curto com um exemplo do dia a dia.

Dá para usar as ferramentas de graça?

Sim. Word, Excel e PowerPoint têm versões gratuitas pelo navegador (em office.com, com uma conta Microsoft) e aplicativos para celular. O Canva tem um plano gratuito. O Power BI Desktop também é gratuito, mas só funciona em computador com Windows. Cada aula avisa se dá para fazer no celular.
