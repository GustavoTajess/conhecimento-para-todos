Sobre o projeto

O que é

O Conhecimento para Todos é um site com aulas gratuitas de Excel, Power BI, Word, PowerPoint e Canva, do básico ao intermediário. Ele foi feito para pessoas sem acesso a cursos pagos, principalmente jovens que querem gerar uma renda extra.

O site é a intervenção de um projeto de extensão do curso de Análise e Desenvolvimento de Sistemas (ADS), no itinerário Economia Sustentável. Projeto de extensão é quando o estudante usa o que aprende na faculdade para ajudar uma comunidade.

Quem faz

O projeto é individual, feito por Gustavo, estudante de ADS.

Onde acontece

O território do projeto é o Jardim Betânia, em Sorocaba (SP). Mesmo assim, o site é aberto: qualquer pessoa pode usar.

Para entender o que as pessoas precisavam, foram usados um questionário online (Google Forms) e conversas com moradores. Os principais resultados serão publicados aqui: [PREENCHER].

Objetivos de Desenvolvimento Sustentável (ODS)

Os ODS são metas da ONU para um mundo mais justo. Este projeto trabalha com três:

  • ODS 4: Educação de qualidade

    Aulas gratuitas, em linguagem simples, para mais gente aprender ferramentas digitais.

  • ODS 8: Trabalho decente e crescimento econômico

    Ensina o que ajuda a criar renda: controlar gastos, fazer currículo, divulgar um serviço.

  • ODS 10: Redução das desigualdades

    Leva para todos um conhecimento que costuma ser vendido em cursos pagos.

Como o projeto é avaliado

Depois que o site for divulgado, as pessoas poderão contar o que acharam em um formulário. Assim o conteúdo melhora com a opinião de quem usa.
